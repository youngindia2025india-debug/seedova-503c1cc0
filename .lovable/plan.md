# Seedova Connect Us Page

## Goal
Create a new `/contact` page that closely reproduces the supplied reference while preserving Seedova’s existing navigation, branding, colors, and application shell.

## What will be built
- A desktop two-column layout with the contact form occupying roughly 54% and the illustrated help panel 46%.
- A white, softly shadowed contact card with the exact requested labels, inputs, contact preference controls, consent checkbox, and Seedova-green submit button.
- A pastel mint/cream/blush help panel with the four requested support categories and decorative handwritten messages.
- A custom editorial line-art mother-and-baby illustration created specifically for this page, visually blended into the panel rather than using the reference screenshot itself.
- A stacked mobile layout that keeps the form, help content, and illustration visible and readable.
- Page-specific title, description, and social metadata.

## Interaction and validation
- Required fields and consent will use browser validation.
- Contact preference options will be selectable.
- Submission will show a local confirmation message; no message delivery service or database changes will be introduced.

## Scope protection
- No changes to authentication, database, existing routes, shared navigation, landing page, or other page content.
- The uploaded image will be used only as visual reference, not embedded in the app.
